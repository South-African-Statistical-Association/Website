# SASA Quarto site

1. Put the SASA logo in `images/logo.png` (replace the placeholder).
2. Put the two SASA colour codes at the top of `styles.scss`.
3. Put the constitution PDF in `about/files/SASA-Constitution-2021.pdf`.
4. Run `quarto preview` to see the site. Run `quarto render` to build it into `_site/`.
